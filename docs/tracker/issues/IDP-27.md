# IDP-27: idp-gate: reject environment markers in build-constraints.txt

Epic/parent: [IDP-16](IDP-16.md)

Links: relates to [IDP-25](IDP-25.md)

## Description

## Context / why

Follow-up from the IDP-24 and IDP-25 security reviews (finding m3; PR #10).

* The drift test parser in `packages/idp-gate/tests/test_profiles.py` (`_parse_constraints`) strips any `; marker` before comparing pins. The synthetic case `file-marker-ignored` asserts this behaviour.
* So a committed line such as `hatchling==1.32.4 ; sys_platform == "never"` passes the drift test, yet it disables that pin for every real build.
* uv likely fails closed with `--require-hashes`, but the drift test should not rely on that.
* The file regenerated by the command in its header currently contains no markers.

## Acceptance criteria

* **AC-1** Given `packages/idp-gate/build-constraints.txt` contains a requirement with an environment marker, when the test session runs, then the drift test fails, names the line, and says it is not an exact `==` pin.
* **AC-2** Given `build-constraints.txt` regenerated with the command in its header, when the test session runs, then the drift tests pass (the regenerated file has no markers).
* **AC-3** (edge) Given the synthetic case `file-marker-ignored`, when this change merges, then that case expects a failure (renamed, e.g. `file-marker-rejected`), and the root-list and uv.lock-record marker handling is unchanged.

## Non-functional criteria

No network at test time. No new dependencies. No extra `uv build` runs. Stdlib only.

## Out of scope

* Markers in the root `build-constraint-dependencies` list (already rejected in IDP-25).
* Hash checking for `uv sync` builds.
* The `UV_LOCKED` / `--locked` follow-up (a separate ticket).

## Interfaces / dependencies

* Depends on IDP-25 (Done). The change is test code only. No protected paths.

## Test approach

* Change the parser and the synthetic cases in `test_profiles.py`, written test-first.
* Add a case with a marker plus hashes on continuation lines, matching the real file format.

## Definition of Done

ACs traced; `make verify` green locally and in CI; ADR-0012 IDP-24/25 notes and CHANGELOG updated.
